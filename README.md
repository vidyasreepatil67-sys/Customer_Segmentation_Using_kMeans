# Customer_Segmentation_Using_kMeans
Customer Segmentation is an unsupervised machine learning project that uses the K-Means clustering algorithm to group customers based on similar characteristics and spending behavior.

The project helps identify different customer groups, which can be useful for understanding customer behavior and creating targeted marketing strategies.

# 1.Python
2.Pandas
3.Matplotlib
4.Scikit-learn
5.K-Means Clustering
